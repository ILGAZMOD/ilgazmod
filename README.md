# Modlama
1.adım:git ile repo'yu klonlayın
kod:git clone https://github.com/ILGAZMOD/ilgazmod.git
2.adım: npm ile modülleri indirin
kod:npm ci

kod:npm start
ve sonra bu websiteye gidin:http://localhost:8601/
daha fazlası için turbowarp docs'a bakabilirsiniz:https://docs.turbowarp.org/development/getting-started
